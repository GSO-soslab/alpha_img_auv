# Cerulean Omniscan 450 FS

Source: <https://docs.ceruleansonar.com/c/omniscan-450/specifications> (read 2026-10-14).
Re-check the page before relying on a value, Cerulean may revise it.

## Specifications

| Attribute | 450 FS 100 m | 450 FS 300 m |
|---|---|---|
| Frequency (nominal) | 450 kHz | 450 kHz |
| Beam width (2-way, 3 dB) | 0.8 deg | 0.8 deg |
| Beam height | 50 deg | 50 deg |
| Vertical beam angle | 0 deg | 0 deg |
| Range resolution | up to 1/1200 of range | up to 1/1200 of range |
| Maximum range | 120 m | 120 m |
| Far field | 5 m | 5 m |
| Maximum ping rate | 20 Hz | 20 Hz |
| Power | 10-30 V, 10 W max (pinging) | 10-30 V, 10 W max (pinging) |
| Data interface | 100BaseT Ethernet | 100BaseT Ethernet |
| Electrical connection | 4-pin JST (Ethernet) + one wire pair (power) | same |
| Weight in air / in water | 440 g / -60 g | 825 g / 325 g |
| Maximum operating depth | 100 m | 300 m |

Notes from the manufacturer: the listed maximum range is where targets have been
comfortably identified (SonarView allows up to 200 m). Beam width is valid beyond the
far-field distance, closer in the beam is wider with larger sidelobes. The FS and SS
names do not limit how either model is used.

## ROS 2 status

- The existing driver is
  [cerulean-omniscan450-frontscan-ros2-driver](https://github.com/Aatmaj9/cerulean-omniscan450-frontscan-ros2-driver)
  (package `frontscan_ros2`, node `frontscan_node`, ROS 2 Humble). Each message is a
  one-dimensional range profile (`FrontScanSonar`, `FrontScanSonarRaw`).
- It is not part of this repo and has not been ported to Jazzy yet.
  `bringup_sonars.launch.py fs450:=true` needs that package and fails without it,
  so the argument defaults to `false`.
- The driver publishes on absolute topics `/frontscan450/range` and
  `/frontscan450/range_raw`. The launch file remaps them to
  `/alpha_img/fs450_port/range` and `/alpha_img/fs450_port/range_raw` so that two
  units do not collide.

## Vehicle integration

- URDF: `fs450_port_link` in `alpha_img_description/urdf/base.urdf`, between the
  `BEGIN`/`END` comments. A second unit (`fs450_stbd`) is included commented out.
  **Mounting position and orientation are placeholders.**
- Config: `config/sensors/cerulean_fs450.yaml`, with the second unit commented out.
  The IP address is the driver's default and must be set to the address configured on
  the sonar.
- Network: Ethernet only, 10-30 V power.
